# ⚡ Графік змін — Мультирічний PWA Календар

Сучасний веб-додаток для автоматичного розрахунку графіка чергувань 5 змін (**А, Б, В, Г, Д**). Працює як Progressive Web App (PWA) — встановлюється на смартфон і працює офлайн.

🔗 **[sunpp-shift-schedule.vercel.app](https://sunpp-shift-schedule.vercel.app)**

---

## 🌟 Можливості

| Функція | Опис |
|---|---|
| 📱 **PWA + Офлайн** | Встановлюється на смартфон/ПК, працює без інтернету |
| 🧮 **15-денний алгоритм** | Точний розрахунок ранку, вечора, ночі та вихідних на будь-який рік |
| 📍 **Автофокус** | Автоматичне центрування на поточній даті при відкритті |
| 📝 **Нотатки** | Відмітки до дат: Зміна, Лікарняний, Відпустка, Інше — з коментарями |
| 📊 **Статистика** | Підрахунок робочих днів, змін, нічних та ін. |
| 💬 **Зворотній зв'язок** | Відгуки надсилаються через захищений серверний бекенд |
| 📲 **Поділитися** | QR-код та копіювання посилання в один клік |
| 🎨 **Теми** | Світла та темна тема оформлення |
| 📱 **Native UI** | Bottom Sheets, Safe Area Insets, запобігання зуму на iOS |

## 🏗️ Архітектура

```
├── index.html          # Головна сторінка
├── style.css           # Стилі (Vanilla CSS)
├── app.js              # Логіка додатку (Vanilla JS)
├── sw.js               # Service Worker (кешування, офлайн)
├── manifest.json       # PWA-маніфест
├── api/
│   ├── send-message.js # Серверна функція (Vercel) — відправка відгуків
│   └── webhook.js      # Telegram Webhook handler
├── icons/              # Іконки додатку
├── robots.txt          # SEO
└── sitemap.xml         # SEO
```

## 🚀 Встановлення на смартфон

### Android (Chrome)
1. Відкрийте сайт у Google Chrome.
2. Натисніть меню (**⋮**) → **«Встановити додаток»**.

### iOS (Safari)
1. Відкрийте сайт у Safari.
2. Натисніть **«Поділитися»** (↑) → **«На Домашній екран»**.
