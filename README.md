# ⚡ Графік змін (PWA Мультирічний Календар)

Сучасний веб-додаток та Progressive Web App (PWA) для автоматичного розрахунку і зручного перегляду графіка чергувань для 5 змін (**А, Б, В, Г, Д**) з підтримкою офлайн-роботи та нотаток.

---

## 🌟 Основні можливості

- **📱 PWA та Офлайн-режим**: Встановлення на робочий стіл смартфона чи комп'ютера. Працює навіть без доступу до Інтернету з автоматичною синхронизацією при відновленні зв'язку.
- **🧮 Точний 15-денний алгоритм**: Автоматичний розрахунок ранку (1), вечора (2), ночі (3) та вихідних на будь-який рік.
- **📍 Автофокус на сьогодні**: При відкритті екран автоматично плавно центрується на поточній даті.
- **📝 Нотатки до дат**: Можливість додавати індивідуальні відмітки (`🏖️ Відпустка`, `🤒 Лікарняний`, `⚡ Понаднормово`, `🔄 Заміна`) та коментарі з переглядом у загальному списку.
- **📊 Telegram Звітність**: Отримання статистики використання та відгуків безпосередньо у Telegram.
- **📲 Поділитися графіком**: Генератор QR-коду та миттєве копіювання посилання в один клік.
- **☀️ / 🌙 Темна та світла теми**: Інтерфейс адаптується під ваші вподобання.
- **🎨 Мобільна верстка у стилі Native App**: Сучасні висувні панелі (Bottom Sheets), безпечні зони для екранів смартфонів (Safe Area Insets) та запобігання випадковому зуму на iOS.

---

## 🚀 Встановлення на смартфон (PWA)

### Android (Chrome)
1. Відкрийте сайт у браузері Google Chrome.
2. Натисніть меню (⋮) та оберіть **«Додати на головний екран»** або **«Встановити додаток»**.

### iOS (Safari / iPhone)
1. Відкрийте сайт у браузері Safari.
2. Натисніть кнопку **«Поділитися»** (кнопка зі стрілкою вгору внизу екрана).
3. Оберіть пункт **«На екран "Домішній"»** (Add to Home Screen).

---

## 💬 Зворотній зв'язок та Telegram Bot

Додаток підтримує інтеграцію з Telegram API для надсилання відгуків, пропозицій та персональної статистики використання. Якщо ви використовуєте власний бот:
1. Натисніть на кнопку **💬 Відгук** у меню додатку.
2. Розгорніть пункт **⚙️ Налаштувати Telegram Bot**.
3. Введіть ваш власний Bot Token та Chat ID для отримання сповіщень.
