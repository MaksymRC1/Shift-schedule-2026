# ⚡ Графік змін (shift_schedule 2025–2030+)

Веб-додаток **«Графік змін»** — це сучасний, мобільний та функціональний календар для автоматичного розрахунку та відображення змін для 5 змін (**А, Б, В, Г, Д**) на будь-який рік з можливості додавання нотаток, аналітики змін, генерації QR-коду, сповіщеннями у **Telegram** та підтримкою **PWA (офлайн-робота)**.

🌐 **Посилання на сайт:** [https://maksymrc1.github.io/shift_schedule/](https://maksymrc1.github.io/shift_schedule/)

## 🌟 Основні можливості

- **🔒 Заборона скролу при відкритому модальному вікні**: Сторінка не прокручується на задньому плані, коли відкрите вікно нотаток чи статистики.
- **📍 Автоматичне фокусування на сьогоднішній даті**: При відкритті додатку екран плавно центрується на сьогоднішньому дні (`cell-today`).
- **◀ ▶ Зручний стрілочний перемикач років**: Лаконічне керування роками (2025, 2026, 2027, 2028, 2029, 2030+).
- **📊 Модуль статистики користувачів та відправка у Telegram**:
  - Підрахунок кількості відкриттів додатку, першого та останнього входу, кількості нотаток та режиму використання (PWA/Браузер).
  - Кнопка **`📊 Надіслати статистику в Telegram`** відправляє звіт особисто вам у Telegram!
- **🧮 15-денний алгоритм чергування змін**: `[1, 1, 1, Вихідний, Вихідний, 3, 3, 3, Вихідний, Вихідний, 2, 2, 2, Вихідний, Вихідний]`.
- **📝 Нотатки з відмітками**: `🏖️ Відпустка`, `🤒 Лікарняний`, `⚡ Понаднормово`, `🔄 Заміна`, `📝 Особисте`.
- **📱 PWA та Офлайн режим**: Встановлення на робочий стіл смартфона чи ПК як окремого додатку.
- **📲 QR-код та посилання**: Генератор QR-коду та копіювання посилання сайту в один клік.

## ⚙️ Як змінити назву репозиторію на `shift_schedule` в GitHub (За бажанням)

Щоб ваша адреса сайту стала `https://maksymrc1.github.io/shift_schedule/`:

1. Відкрийте ваш репозиторій на [GitHub.com](https://github.com/MaksymRC1/Shift-schedule-2026).
2. Натисніть **Settings** ⚙️.
3. У найпершому полі **Repository name** виправте `Shift-schedule-2026` на **`shift_schedule`**.
4. Натисніть **Rename**.

GitHub автоматично перенаправить репозиторій та оновить посилання сайту на:
`https://maksymrc1.github.io/shift_schedule/`
