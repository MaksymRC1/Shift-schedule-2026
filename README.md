# ⚡ Графік змін (Shift Schedule 2025–2030+)

Веб-додаток **«Графік змін»** — це сучасний, мобільний та функціональний календар для автоматичного розрахунку та відображення змін для 5 змін (**А, Б, В, Г, Д**) на будь-який рік з можливістю додавання персональних нотаток, аналітики змін, генерації QR-коду та повноцінною підтримкою **PWA (офлайн-робота)**.

## 🌟 Основні можливості

- **🧮 Автоматичний генератор змін на будь-який рік**:
  - Безперервний 15-денний цикл чергування змін: `[1, 1, 1, Вихідний, Вихідний, 3, 3, 3, Вихідний, Вихідний, 2, 2, 2, Вихідний, Вихідний]`.
  - Підтримуються всі роки (2025, 2026, 2027, 2028, 2029, 2030+).
  - Швидкий перемикач років та ввід будь-якого року в поле.

- **📝 Модуль персональних нотаток**:
  - Клік по будь-якій клітинці дати відкриває модальне вікно.
  - Позначки статусів: `🏖️ Відпустка`, `🤒 Лікарняний`, `⚡ Понаднормово`, `🔄 Заміна`, `📝 Особисте`.
  - Збереження у `localStorage` — нотатки залишаються у браузері.
  - Окреме вікно `📋 Нотатки` для пошуку та швидкого керування всіма нотатками.

- **📱 PWA та Офлайн режим**:
  - Встановлення на робочий стіл смартфона чи ПК як окремого додатку.
  - Service Worker (`sw.js`) кешує всі файли та забезпечує роботу без інтернету.

- **📲 Генератор QR-коду та посилання**:
  - Кнопка `📲 QR-код` для швидкої генерації QR-коду та посилання на сайт.
  - Підтримка копіювання посилання в один клік та системного меню `Share`.

- **💬 Модуль зворотного зв'язку**:
  - Кнопка `💬 Відгук` з формою оцінки додатку (1–5 зірочок ⭐), вибором категорії та можливістю відправити пропозицію чи зауваження.

- **📊 Аналітика та статистика змін**:
  - Автоматичний підрахунок кількості ранкових (1), вечірніх (2), нічних (3) змін, вихідних та днів відпустки для кожної зміни окремо чи для всіх разом.

- **🎨 Сучасний адаптивний UI**:
  - Темна та світла теми (збереження вибору користувача).
  - Закріплені шапки дат та закріплена колонка змін при прокручуванні.
  - Оптимізована мобільна верстка з мобільними шторками (bottom drawers).
  - Готовий модуль друку (`🖨️ Друк / PDF`).

## 🚀 Як розгорнути на GitHub Pages

Додаток побудовано на чистому **HTML, CSS та JavaScript** і він ідеально працює з **GitHub Pages**:

1. **Завантажте код у ваш GitHub репозиторій**:
   ```bash
   git add .
   git commit -m "Рефакторинг графіку змін, PWA, QR-код та відгуки"
   git push origin main
   ```

2. **Увімкніть GitHub Pages**:
   - Перейдіть у ваш репозиторій на [GitHub.com](https://github.com).
   - Натисніть **Settings** ⚙️ ➔ **Pages**.
   - У розділі **Build and deployment**:
     - **Source**: виберіть `Deploy from a branch`.
     - **Branch**: виберіть `main` і папку `/ (root)`.
     - Натисніть **Save**.

За 1–2 хвилини сайт буде опубліковано за адресою:
`https://<ваш-логін>.github.io/<назва-репозиторію>/`

## 📁 Структура проєкту

```text
├── index.html       # Головна сторінка та структура модальних вікон
├── style.css        # Дизайн-система, PWA стилі, мобільна верстка, темна/світла теми
├── app.js           # Алгоритм обчислення змін, нотатки, QR-код, відгуки
├── sw.js            # Service Worker для офлайн-кешування (PWA)
├── manifest.json    # Маніфест PWA додатку
├── icons/           # Іконка додатку (icon.svg)
└── README.md        # Документація проєкту
```
